# Part Scout Mobile

**eBay Motorsの日本車純正部品を自動探索し、iPhoneで仕入れ候補を上から順に処理するPWA**です。

GitHub Actionsが毎日、検索語のローテーション、純正品番抽出、同一品番の市場調査、販売ペース学習、楽天仕入価格、為替、手数料、関税概算、利益判定まで実行します。日常操作は、画面の「今日やる」に表示される黄色い「次にすること」を上から処理するだけです。

> **重要**
> eBayの承認済みアカウントではMarketplace Insightsから公式の過去90日成約数・最終成約価格を自動取得します。このAPIは利用制限があるため、未承認の場合は操作不要でBrowse APIの日次差分推定へ切り替わります。Product Researchは任意の照合機能です。

## v0.3.1で直したこと

- Marketplace Insightsの公式90日成約APIを自動試行
- 利用承認済みなら公式成約数・最終成約価格を自動採用
- 未承認・一時障害・完全一致なしの場合は日次差分推定へ自動フォールバック
- 公式成約APIの結果は同一品番の完全一致だけを集計し、重複Item IDを二重加算しない
- 関税を「確定税率」ではなくHTSUS・原産国・DDP確認前のスクリーニング仮置きとして明示
- UIへ販売データの出所（eBay公式90日／自動差分）と成約相場・出品相場の区別を表示

## v0.3.0で直したこと

- 1～2日分の差分を90日へ過大換算しないよう、7日未満は数値判定から除外
- 各出品をそれぞれの観測期間で換算し、終了・売切れで消えた出品も追跡集計
- 観測期間の中央値が30日以上、競合精度が高く、市場カバーが50%以上、追跡出品数も十分な場合だけ「自動精度・高」
- Product Research入力を必須から任意へ変更
- 楽天公式商品検索APIによる品番一致価格の自動取得を追加
- ECB基準レートからUSD/JPYを毎日自動更新
- eBay手数料の現行料率、固定手数料、海外決済手数料のボリューム割引、日本の消費税10%を分離計算
- Basic以上はeBayのカテゴリーパスから、標準P&A・タイヤ・アパレル・車載テックの料率を自動選択
- Payoneer出金手数料と、条件該当時の年間アカウント手数料29.95USDを分離計算
- 日本原産15%を一次判定に使用し、原産国不明は保守的な25%で仮計算
- UIを「1 今日やる → 2 全候補 → 3 精度補正 → 4 設定」の順番型へ変更

## 自動化される範囲

| 処理 | 自動化 | 内容 |
|---|---|---|
| eBay候補探索 | 自動 | 日本車メーカー、純正語、小型部品語を重複しない順でローテーション |
| 純正品番抽出 | 自動 | Item Specifics優先、タイトルを補助利用 |
| 同一品番市場調査 | 自動 | 競合数、セラー数、価格中央値、価格帯を集計 |
| 90日販売ペース | 自動 | 承認済みならeBay公式90日成約、未承認なら日次差分推定 |
| 終了出品の販売分 | 自動 | 調査中に消えた出品も履歴に残して合算 |
| 楽天仕入価格 | 自動・任意設定 | 楽天公式APIで品番完全一致を優先 |
| モノタロウ | 1タップ | 公開商品APIを前提にせず、品番入力済み検索画面を開く |
| 為替 | 自動 | ECBの日次EUR基準レートからUSD/JPYを算出 |
| 国際送料 | 自動概算 | 商品名から小型・超小型を分類。低信頼のため仕入前確認必須 |
| eBay手数料 | 自動 | プラン、カテゴリー、売上総額、前々月売上から計算 |
| Payoneer | 自動概算 | 出金率と年間手数料を別計算 |
| 米国関税 | 自動概算 | 構造化された原産国情報を使い、未確認品は保守的に計算 |
| 利益判定 | 自動 | 利益、利益率、需要、競合、販売精度、確認状態を総合判定 |

有料API、生成AI API、OCR、外部データベースは使用しません。GitHub Actions、GitHub Pages、eBay Browse API、利用承認時のMarketplace Insights API、楽天公式API、ECB公開レートを使います。

## 初回だけ行う設定

### 1. eBay Productionキー

対象リポジトリで次を開きます。

`Settings` → `Secrets and variables` → `Actions` → `New repository secret`

| Secret名 | 内容 |
|---|---|
| `EBAY_CLIENT_ID` | Production App ID / Client ID |
| `EBAY_CLIENT_SECRET` | Production Cert ID / Client Secret |

Client Secretはソースコード、JavaScript、READMEへ書かないでください。

### 2. 楽天APIキー（推奨、無料枠で使用）

楽天価格を自動取得する場合だけ登録します。

| Secret名 | 内容 |
|---|---|
| `RAKUTEN_APPLICATION_ID` | 楽天ウェブサービスのApplication ID |
| `RAKUTEN_ACCESS_KEY` | 楽天ウェブサービスのAccess Key |

未登録でもアプリは動作し、楽天とモノタロウの品番検索ボタンを使えます。

### 3. GitHub Pages

`Settings` → `Pages` → `Build and deployment` → `Source`を **GitHub Actions** にします。

### 4. 初回調査

`Actions` → `eBay自動リサーチ` → `Run workflow`

検索語は空欄のままで構いません。成功すると、実データと学習状態が`main`へ保存され、Pagesが更新されます。

## iPhoneで使う

1. `Settings` → `Pages`の公開URLをSafariで開く
2. 共有ボタン → `ホーム画面に追加`
3. ホーム画面の`Part Scout`を開く
4. `1 今日やる`に表示された候補を上から処理

## 日常操作

### 通常日

1. `今日やる`を開く
2. 最上部の「最初にすること」を確認
3. 各カードの黄色い「次にすること」だけ処理
4. `購入候補`になった品番のみ最終確認

### 自動で楽天価格が取れた場合

1. 楽天リンクで在庫・税込価格・送料を確認
2. `金額を修正・最終確認`を開く
3. `仕入価格・在庫・送料を確認済み`にチェック
4. 原産国とDDP関税を確認してチェック

### 楽天で見つからない場合

1. モノタロウまたは楽天の品番検索ボタンを押す
2. 仕入価格を1回入力
3. 以後はiPhone内に保存された価格で自動再計算

Product Researchは、導入後30日を待たずに上位品番を確認したい場合だけ使用します。

## 90日販売ペースのロジック

### 優先順位

1. **Marketplace Insights利用承認あり**：eBay公式の過去90日成約数と最終成約価格を自動使用
2. **未承認・一時障害・完全一致なし**：日次スナップショットの販売増分推定へ自動切替
3. **Product Research**：任意の照合・補正のみ

Marketplace Insightsは限定公開のため、通常のClient ID／Secretだけでは利用できない場合があります。その場合もエラーで停止せず、同じ画面・同じ操作で差分推定を継続します。

### 差分推定の計算対象

- 同一品番と確認できた出品
- 現在出品中の商品
- 調査期間中に終了・売切れで消えた商品
- アプリが観測を開始した後の`estimatedSoldQuantity`増分のみ

観測開始前の累計販売数を「90日販売実績」として足しません。

### 出品ごとの計算

```text
出品ごとの90日換算 = 観測期間内の販売増分 ÷ その出品の観測日数 × 90
品番の90日換算ペース = 同一品番の各出品の90日換算を合算
```

販売数がリセットされた場合、減少分はマイナス販売として扱わず、その後の正の増分だけを使います。

### 信頼度

| 表示 | 条件の概略 | 扱い |
|---|---|---|
| 自動学習中 | 有効な観測差分が7日未満 | 仕入判定には使わない |
| 自動精度・低 | 観測中央値7～13日 | 参考値 |
| 自動精度・中 | 観測中央値14～29日 | 一次選別 |
| 自動精度・高 | 30日以上＋競合精度高＋市場カバー50%以上＋追跡数十分 | Product Researchなしで自動確認値として利用 |
| eBay公式・過去90日 | Marketplace Insights利用承認＋完全一致 | 公式成約実績 |
| Product Research確認済み | CSV／手入力で補正 | 任意の即時上書き |

「eBay公式・過去90日」は成約実績です。「自動精度・高」は公式履歴ではなく、継続観測に基づく販売ペース推定です。

## 競合数のロジック

品番検索の`total`には類似品番や適合記載だけの商品が混ざるため、そのまま競合数にしません。

```text
推定競合数 = 品番検索総件数 × 返却サンプル内の同一品番一致率
```

実際に詳細確認できた件数より小さくならないよう補正し、返却数、一致数、一致率に応じて`高／中／低／不明`を表示します。

## 手数料計算

2026年8月15日時点の公式情報を初期値にしています。販売前に最新条件も確認してください。

### eBay Motors Parts & Accessories

| 条件 | 初期計算 |
|---|---:|
| ストアなし／Starter | 売上総額7,500USDまで13.6%、超過部分2.35% |
| Basic以上・標準P&A | 1,000USDまで11.5%、超過部分2.35% |
| Basic以上・タイヤ | 1,000USDまで9.5%、超過部分2.35% |
| Basic以上・アパレル等 | 1,000USDまで12.7%、超過部分2.35% |
| Basic以上・車載テック | 1,000USDまで9.35%、超過部分2.35% |
| 取引固定料 | 総売上10USD以下0.30USD、超過0.40USD |
| 出品手数料 | 無料枠内0。枠超過時は設定画面で1件額を入力 |

手数料ベースの売上総額には、商品価格、購入者負担送料、想定米国売上税を含めます。カテゴリー例外はeBayから取得したカテゴリーパスで自動選択します。

### 日本セラーの海外決済手数料

前々月売上を設定すると自動で次の率を選択します。

| 前々月売上 | 率 |
|---:|---:|
| 3,000USD未満 | 1.35% |
| 3,000～9,999.99USD | 1.20% |
| 10,000～49,999.99USD | 0.95% |
| 50,000～99,999.99USD | 0.70% |
| 100,000USD以上 | 0.40% |

eBayの落札手数料、固定料、海外決済手数料、広告費、出品手数料の合計に、日本の消費税10%を加算します。Below StandardやService Metricsによる追加落札手数料は`追加落札手数料`へ入力できます。

### Payoneer

- eBayからPayoneerへの入金手数料ではなく、Payoneerから銀行へ出金する際の率を計算
- 初期値3%
- 公式の一般的な案内は取引経路により1～4%
- 実アカウントの`手数料`表示が分かれば、設定画面で1回だけ変更
- 連続12か月の受取が6,000USD未満で年間アカウント手数料29.95USDが発生する条件を、推定注文数へ自動配賦
- 初年度や契約条件で対象外ならチェックを外せる

## 米国関税

- 日本原産と構造化情報で確認できた自動車部品は、スクリーニング仮置きとして15%を使用
- 原産国不明は25%で保守的に仮計算
- 米国原産は0%で仮計算
- 800USD以下の少額輸入免税は、現在の仕入判断では前提にしない

15%は全商品に対する確定税率ではありません。正確な税率は、品目別HTSUS、材質、原産国、Section 232等の適用範囲、輸入日時点の措置、通関方式で変わります。アプリは最終仕入れ前に`原産国・DDP関税を確認済み`を必須にし、確認前は`概算候補`に止めます。

## 利益判定

### 概算候補

- 利益・利益率・市場条件を満たす
- ただし、販売差分30日、仕入条件、原産国・関税のいずれかが未確認

### 購入候補

次をすべて満たす場合だけ表示します。

- 予想利益5,000円以上
- 利益率25%以上
- 90日換算販売ペース3個以上
- 市場スコア55以上
- 販売ペース÷競合0.10以上
- eBay公式90日実績、自動差分が自動精度・高、またはProduct Research確認済み
- 仕入価格・在庫・国内送料を確認済み
- 国際送料を確認済み
- 原産国・DDP関税を確認済み

市場スコアは一次選別用の独自指標で、利益を保証しません。
