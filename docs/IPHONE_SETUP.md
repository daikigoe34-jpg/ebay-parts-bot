# iPhone設定と使い方

## 1. 公開URLを開く

1. GitHubで`daikigoe34-jpg/ebay-parts-bot`を開きます。
2. `Settings` → `Pages`を開きます。
3. `Build and deployment`のSourceが`GitHub Actions`であることを確認します。
4. `Your site is live at ...`のURLをSafariで開きます。

表示されない場合は、`Actions` → `GitHub Pages公開`の失敗内容を確認します。

## 2. ホーム画面へ追加

1. 公開URLをSafariで開きます。
2. 共有ボタンを押します。
3. `ホーム画面に追加`を押します。
4. 名前が`Part Scout`であることを確認します。
5. `追加`を押します。

以後はホーム画面のアイコンから起動できます。

## 3. 最初に1回だけ設定

画面の`4 設定`を開きます。

1. eBayストアを選びます。
2. 海外決済手数料の割引を反映するため、前々月のeBay売上を入力します。
3. Payoneerアカウント内に表示される出金率が分かれば、初期3%から変更します。
4. 無料出品枠を超える場合だけ、出品手数料／1件を入力します。
5. `設定を保存`を押します。

為替は初期状態で毎日自動更新されます。

## 4. 毎日の使い方

1. `1 今日やる`を開きます。
2. 最上部の`最初にすること`を確認します。
3. 表示された上位カードから、黄色い`次にすること`だけ処理します。
4. 楽天価格が自動取得済みなら、楽天リンクで在庫・税込価格・送料だけ確認します。
5. 楽天価格がない場合は、楽天またはモノタロウの検索ボタンを押し、仕入価格を入力します。
6. `金額を修正・最終確認`を開き、仕入条件を確認済みにします。
7. 原産国とDDP関税を確認し、関税確認済みにします。
8. `購入候補`になった商品だけ仕入れを検討します。

## 5. 販売ペースの精度

- 7日未満：自動学習中
- 14日以上：自動精度・中
- 30日以上かつ市場カバー十分：自動精度・高

通常はProduct Researchを入力しなくても構いません。初回からすぐ判断したい上位品番だけ、`3 精度補正`でCSVまたは手入力を使います。

## 6. 今すぐ再調査する

画面上部の`今すぐ更新`を押すと、GitHubの`eBay自動リサーチ`ワークフローが開きます。

1. GitHubへログインします。
2. `Run workflow`を押します。
3. 検索語は空欄のままで構いません。
4. 緑色で完了後、Part Scoutへ戻ります。
5. 右上の`↻`を押します。

`↻`だけでは調査を開始せず、保存済みデータを再読込します。

## 7. データ保存

手動修正した価格、送料、Payoneer設定、関税確認、Product Research補正は、そのiPhoneのSafari内だけに保存されます。Safariのサイトデータを削除すると消えるため、必要なときは画面下の`現在の一覧をCSV保存`を使ってください。
