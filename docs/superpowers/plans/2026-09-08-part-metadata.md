> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Execute continuously; implementation and existing-Site publication are already authorized by the user. Sites work is controller-only.

**Goal:** Replace repeated parcel questions with part-number lookup, sourced item specifications, packaging estimates and reusable measured parcels on the existing mobile application.

**Spec:** `docs/superpowers/specs/2026-09-08-part-metadata.md`

**Architecture:** Standard-fetch ESM metadata service behind the existing Site; framework-free shared browser modules and immediate local persistence; deterministic box selection feeds the existing shipping estimator. No paid API or secret.

**Tech stack:** JavaScript / Node tests / Web Fetch API / current vanilla HTML / Cloudflare Worker / existing GitHub CI.

## Global Constraints

- Do not invent dimensions, weights, rates, identity, source freshness or API success. Missing/conflicting data cannot generate an automatic parcel. Item dimensions are not shipping dimensions.
- Preserve existing scalar cost records, storage keys, legacy backups, reference-only quote status, manual quotes, tariff and supplier confirmation guards.
- Allowed remote hosts are the four verified dealer hosts only; public product routes only; respect robots, no 403 bypass, no paid APIs, no arbitrary URL fetch, bounded redirects/time/response size.
- Keep the existing Site project and owner-private access. Only the controller edits `/workspace/sites/part-scout-mobile` or calls Sites tools. Implementers work only in the original repository worktree and never spawn other agents.
- No real source data or test fixtures should assert all listings are accurate or independent. Store only the few factual specifications required, never entire product pages.
- Tests exercise actual parsers, persistence, boxing, UI state and HTTP boundaries; mock only external HTTP/storage failures. UI DOM tests may use a pinned jsdom development dependency if needed, with a lockfile. No runtime dependency is needed.
